# Rider–Waite–Smith card images

This directory contains the 78 card faces and one card back from the 1909 Rider–Waite–Smith tarot deck.

- Source: <https://github.com/sixseeds/tarot-api>
- Original artist: Pamela Colman Smith
- Source repository notice: the 1909 card images are public domain

The application uses only the images. Its Korean meanings and interpretations come from this project's deterministic, rule-based TypeScript modules.

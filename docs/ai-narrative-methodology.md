# AI Narrative Methodology

## 역할 분리

AI 내러티브 계층은 사주 값을 계산하지 않는다. 입력은 다음 결정론적 TypeScript 모듈이 이미 만든 구조화된 결과뿐이다.

- `src/engine/saju`: 사주 계산
- `src/engine/tarot`: 카드 추첨
- `src/interpretation`: 규칙 기반 해석과 근거
- `src/narrative`: 구조화된 결과를 상담문으로 표현하는 프롬프트

API 경로는 `app/api/narrative/route.ts`이며 OpenAI API 키는 서버 환경에서만 읽는다. 클라이언트 번들에는 키를 포함하지 않는다.

## 금지 범위

모델에는 다음 작업을 명시적으로 금지한다.

- 사주·간지·절기·기둥·오행·십성·세운 값의 계산, 수정 또는 추정
- 입력에 없는 합충, 신강·신약, 용신·희신, 대운 또는 음력 변환의 생성
- 원본 Palm 사진을 보았다고 주장하거나 confidence 0인 mock 관찰을 실제 특징으로 설명하는 행위
- 개인화/mock 이름 결과로 획수·음양·오행·길흉을 생성하는 행위
- 의료·법률·투자 판단과 미래 사건의 단정

모델 출력은 계산 결과가 아니라 표현 계층이다. 계산 및 규칙 기반 결과는 모델 출력과 독립적으로 UI에 먼저 표시된다.

## 모델과 데이터 처리

- 기본 모델: `gpt-5.6-luna`
- 모델 변경: 서버 환경변수 `OPENAI_MODEL`
- API 키: 서버 환경변수 `OPENAI_API_KEY`
- Responses API 요청은 `store: false`로 전송한다.
- AI에는 구조화된 통합 결과와 Name/Palm 결과만 전달하며 생년월일 원문이나 Palm 원본 이미지는 전달하지 않는다.
- 사용자 질문은 500자로 제한하며 전체 요청은 50,000자로 제한한다.

운영 배포 전에는 조직의 개인정보 처리 기준, OpenAI 데이터 정책, 비용 한도와 사용량 모니터링을 별도로 확인해야 한다.
